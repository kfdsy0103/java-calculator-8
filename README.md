# java-calculator-precourse

## 구현할 기능 목록

- 문자열 입력 기능
    - 사용자로부터 양수 및 구분자로 구성된 문자열을 입력받음


- 커스텀 구분자 파싱 기능
    - 문자열 가장 앞, "//"와 "\n" 사이에 정의


- 문자열에서 숫자를 파싱하는 기능
    - 기본 구분자 : ,(쉼표) :(콜론)
    - 커스텀 구분자 : 문자열 가장 앞, "//"와 "\n" 사이에 정의


- 문자열 검증 기능
    - 수는 양수로만 구성됨
    - 잘못된 값이 들어왔다면 **IllegalArgumentException**을 발생시키고 어플리케이션을 종료함


- 숫자의 합을 계산하는 기능
    - 숫자 리스트를 받아 합계를 반환


- 결과 출력 기능
    - "결과 : 3" 과 같은 형식
